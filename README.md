# Atomic Boost

โปรแกรมปรับแต่ง Windows 10 / 11 ให้เล่นเกมลื่นขึ้น ใช้ได้ทั้ง PC และโน้ตบุ๊ก กดปุ่มเดียวจบ และย้อนกลับได้ทุกอย่าง

## ดาวน์โหลด

1. โหลด `Atomic.exe` จากหน้า [Releases](https://github.com/kaiserxzen-arc/Atomic-Boost/releases/latest)
2. ดับเบิลคลิกได้เลย ไม่ต้องติดตั้ง (Windows 10 / 11 แบบ 64-bit)
3. ถ้า Windows ขึ้นเตือน (SmartScreen) ให้กด **More info** แล้ว **Run anyway** เพราะไฟล์ยังไม่ได้เซ็นชื่อดิจิทัล

## วิธีใช้

1. เปิด `Atomic.exe` แล้วกด **Yes** ที่หน้าต่างขอสิทธิ์ Administrator
2. กดปุ่มแดง **One-Click Boost** ที่มุมขวาบน
3. รีสตาร์ตเครื่อง

## ทำอะไรได้บ้าง

| หน้า | ทำอะไร |
|---|---|
| Dashboard | ดู CPU / RAM / GPU แบบสด และคะแนนการปรับแต่ง |
| Tweaks | ปรับค่า Windows กว่า 80 รายการ เปิดปิดทีละตัวได้ |
| Cleaner | ล้างไฟล์ขยะ ไฟล์ที่กำลังใช้อยู่จะถูกข้าม |
| Startup | เลือกโปรแกรมที่เปิดพร้อม Windows |
| Game Mode | เตรียมเครื่องเองตอนเปิดเกม และคืนค่าเมื่อเลิกเล่น |
| Quick Boost | ปิดแอปเบื้องหลัง คืน RAM ก่อนเข้าเกม |
| Specs | สเปกเครื่องและการตรวจสุขภาพเครื่อง |
| Settings | ภาษาไทย / English, จุดคืนค่าระบบ, ย้อนการเปลี่ยนแปลงทั้งหมด |

## ปลอดภัยไหม

- เก็บค่าเดิมไว้ก่อนแก้ทุกครั้ง ปิดสวิตช์เมื่อไหร่ก็ได้ค่าเดิมคืน หรือกด **Revert all** เพื่อย้อนทั้งหมด
- สร้าง System Restore point ให้ก่อนเปลี่ยนครั้งแรก (ถ้าเปิด System Protection ไว้)
- One-Click Boost ไม่แตะการตั้งค่าที่ลดความปลอดภัยของเครื่อง
- โหมดเกมปิดเฉพาะแอปที่คุณเลือกไว้เอง
- บนโน้ตบุ๊ก การตั้งค่าพลังงานมีผลเฉพาะตอนเสียบปลั๊ก
- สิ่งเดียวที่ย้อนในโปรแกรมไม่ได้คือแอป Store ที่สั่งถอน ต้องลงใหม่จาก Microsoft Store

## Build เอง

ต้องมี [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) แล้วรัน `build.bat`
