# Atomic

โปรแกรม optimize Windows 10 / 11 สำหรับ PC และ Laptop เขียนด้วย C# WPF (.NET 8)
สแกนฮาร์ดแวร์ตอนเปิดแล้วปรับคำแนะนำให้เข้ากับเครื่องเอง (Desktop/Laptop, Intel/AMD, NVIDIA/AMD/Intel, SSD/HDD)

## ดาวน์โหลด

1. ไปที่หน้า [Releases](https://github.com/kaiserxzen-arc/Atomic-Boost/releases/latest) แล้วโหลด `Atomic.exe`
2. ดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม (รองรับ Windows 10 / 11 แบบ 64-bit)
3. ไฟล์ไม่ได้เซ็นชื่อดิจิทัล Windows SmartScreen อาจขึ้นเตือน ให้กด "More info" แล้ว "Run anyway" ส่วนค่า SHA-256 ของไฟล์อยู่ในหน้า Release ใช้ตรวจว่าไฟล์ไม่ถูกแก้

## วิธีใช้

1. ดับเบิลคลิก `Atomic.exe` แล้วกด Yes ที่หน้าต่างขอสิทธิ์ Administrator
2. หน้า **Specs & Health**: ตรวจว่าตรวจจับฮาร์ดแวร์ถูกต้อง และอ่าน Health check
3. กดปุ่มแดง **One-Click Boost** ที่มุมขวาบน (หรือปุ่มเดียวกันบนหน้า Dashboard) เพื่อใช้ทุก tweak ที่แนะนำสำหรับเครื่องนี้ และเปิด Auto Game Mode ไปพร้อมกัน (สร้าง System Restore point ให้ก่อน ส่วนการปิดแอปตอนเข้าเกมยังคงตามที่ตั้งไว้ ไม่ถูกเปิดให้เอง)
4. Restart เครื่อง


## หน้าต่าง ๆ

| หน้า | ทำอะไร |
|---|---|
| Dashboard | CPU / RAM / GPU / Disk แบบสด, คะแนนการ optimize, process ที่กินทรัพยากรสูงสุด |
| Windows Tweaks | 85 tweaks แบ่ง 10 หมวด เปิด/ปิดทีละตัวได้ ชี้เมาส์ที่ไอคอน (i) ท้ายชื่อเพื่อดูว่าแก้ค่าอะไรบ้าง |
| Cleaner | ลบไฟล์ขยะ: temp, Windows Update cache, crash dumps, log, thumbnail, browser cache, shader cache, Recycle Bin |
| Quick Boost | ปุ่มที่กดเองก่อนเข้าเกม: ปิดแอปเบื้องหลัง, คืน RAM, ล้าง DNS, รีสตาร์ต Explorer |
| Auto Game Mode | ตรวจจับเกมเอง เตรียมเครื่องตอนเกมเริ่ม และคืนค่าเมื่อเลิกเล่น ไม่มีการบันทึกสถิติการเล่น |
| Startup Apps | เปิด/ปิดโปรแกรมที่รันตอนเปิดเครื่อง (วิธีเดียวกับ Task Manager ไม่ลบอะไร) |
| Specs & Health | สเปกเครื่อง, Health check, พื้นที่ไดรฟ์ |
| Settings & Backups | ภาษา, Restore point, Revert all, activity log |

## หน้าตาและภาษา

- **ภาษา:** ไทย / English สลับได้จากปุ่มรูปลูกโลกบนแถบด้านบน หรือในหน้า Settings & Backups ครั้งแรกจะเลือกตามภาษาของ Windows
- **หน้าตา:** มีแบบเดียวคือดำแดงแบบกระจก (ไม่มีตัวเลือกธีม) ใช้ฟอนต์ Kanit ที่ฝังมากับโปรแกรม
- **เมนู:** แถบด้านบนมีโลโก้ ชื่อหน้าทั้ง 9 หน้า และปุ่ม One-Click Boost ชี้เมาส์ที่ชื่อหน้าเพื่อดูว่าหน้านั้นใช้ทำอะไร ช่องค้นหา tweak อยู่ในหน้า Tweaks
- **คำอธิบาย:** ข้อความยาวถูกย่อเหลือไม่เกินสองบรรทัด ชี้เมาส์ที่ข้อความหรือที่ไอคอน (i) เพื่ออ่านฉบับเต็ม
- **Animation:** มีเฉพาะการตอบสนองเล็ก ๆ ตอนชี้เมาส์และตอนกด เช่น ปุ่ม One-Click Boost ขยายเล็กน้อย สายฟ้าสั่น และมีวงแหวนวิ่งออกตอนคลิก ไม่มี animation เต็มหน้าต่างและไม่มีอะไรวิ่งตลอดเวลา พื้นหลังเป็นภาพนิ่ง ขณะเปิดหน้า Dashboard ทิ้งไว้ใช้ CPU ราว 2-3% ของหนึ่งคอร์บนเครื่องทดสอบ
- **เสียงปุ่ม:** มีเสียงเฉพาะปุ่ม Boost ปุ่มหลักสีแดง และสวิตช์เปิดปิด เมนู แท็บ และปุ่มย่อยไม่มีเสียง เสียงสร้างจากโค้ดใน `Core/Sound.cs` ไม่มีไฟล์เสียง ปิดได้ในหน้า Settings & Backups
- **เปิดพร้อม Windows:** สวิตช์ในหน้า Settings & Backups สร้าง Task Scheduler ชื่อ "Atomic Boost" ให้เปิด Atomic ด้วยสิทธิ์สูงสุดตอนเข้าสู่ระบบ (หน่วง 15 วินาที) แบบซ่อนไว้ข้างนาฬิกา ไม่มีหน้าต่าง UAC ถ้าย้ายโฟลเดอร์ ตอนเปิดครั้งถัดไป task จะถูกแก้ให้ชี้ที่ใหม่เอง
- **เปลี่ยนหน้า:** ทุกหน้าถูกเตรียมไว้ล่วงหน้าตอนโปรแกรมว่างหลังเปิด การเปลี่ยนหน้าจึงเป็นแค่การสลับการแสดงผล พร้อม animation เลื่อนเข้าสั้น ๆ ครั้งเดียว
- ค่าทั้งหมดเก็บใน `C:\ProgramData\OptiForge\settings.json` (โปรแกรมเคยชื่อ OptiForge และ Vortex โฟลเดอร์ข้อมูลจึงใช้ชื่อเดิมต่อไป เพื่อให้ค่าที่สำรองไว้ยังใช้คืนค่าได้)

## Auto Game Mode

ปิดอยู่ตั้งแต่ต้น เปิดได้ในหน้า Auto Game Mode หรือด้วยปุ่ม One-Click Boost และทำงานขณะที่ Atomic เปิดอยู่ (ย่อหน้าต่างไว้ได้) ด้วยสิทธิ์ Administrator

- **นับว่าเป็นเกมเมื่อ** เป็นหน้าต่างที่ใช้งานอยู่ และอยู่ในรายการเกม (การ์ด My games ในหน้าเดียวกัน) หรือติดตั้งในคลังเกมของ Steam, Epic, Riot, Xbox, Ubisoft, EA, GOG, Rockstar ไฟล์ launcher และตัวช่วยไม่นับ ถ้าตรวจผิดกด "Not a game" ในบันทึกการเล่นได้
- **การปิดแอป** เป็นสวิตช์แยกที่ปิดอยู่ตั้งแต่ต้น และปิดเฉพาะแอปที่เปิดสวิตช์ไว้ในรายการ "Apps to close" เท่านั้น ไม่มีการเดาเอง โปรแกรมจะขอปิดแบบปกติก่อน แอปที่ถามเรื่องงานยังไม่บันทึกจะถูกปล่อยไว้ทั้งแอป ส่วนโปรเซสของ Windows, launcher เกม และเกมในรายการของคุณเพิ่มเข้ารายการไม่ได้
- **ระหว่างเล่น** (เลือกเปิดปิดทีละข้อ): โหมดพลังงาน Best Performance, CPU priority ระดับ High, ตั้งการ์ดจอแยกให้เกมที่ยังไม่เคยตั้ง, คืน RAM, ล้าง standby memory เมื่อ RAM ว่างต่ำกว่า 1 GB, ตรึง timer 0.5 ms
- **เมื่อเลิกเล่น** คืนโหมดพลังงานและ timer เปิดแอปที่ปิดไปกลับมา แล้วบันทึกผลของรอบนั้น (FPS เฉลี่ย, 1% low, CPU, GPU, RAM, อุณหภูมิ, การถูกจำกัดความเร็ว) ไว้เทียบกับรอบก่อนของเกมเดียวกัน
- **ระหว่างเล่น** โปรแกรมไม่เก็บสถิติและไม่นับ FPS ทุก 3 วินาทีจะเช็กแค่ว่าเกมยังเปิดอยู่ ส่วนอุณหภูมิจะอ่านเฉพาะเมื่อเปิด Heat Guard และหน่วยความจำจะเช็กเฉพาะเมื่อเปิดการล้าง standby memory
- **ตรวจจับผิด** ถ้าโหมดเกมเปิดให้โปรแกรมที่ไม่ใช่เกม กดปุ่ม "ไม่ใช่เกม" บนการ์ดสถานะในหน้า Auto Game Mode
- **Heat Guard** ถ้า CPU ร้อนถึง 95 C หรือ GPU ถึง 87 C ต่อเนื่อง 30 วินาทีระหว่างเล่น จะลด turbo ของ CPU ลงหนึ่งขั้น (ขั้น 1 จำกัดความถี่ไว้ราว 15% เหนือ base clock, ขั้น 2 ปิด turbo) แล้วรออย่างน้อย 1 นาทีก่อนตัดสินอีกครั้ง โปรแกรมจำขั้นที่เครื่องนั้นต้องใช้ไว้ และใช้ตั้งแต่เริ่มเกมทุกครั้ง แต่มีผลเฉพาะตอนเกมรัน เมื่อปิดเกม (หรือเปิดโปรแกรมครั้งถัดไปหลังเครื่องดับกะทันหัน) ค่าพลังงานของ CPU จะกลับเป็นค่าเดิม งานอื่นจึงได้ความเร็วเต็ม tweak ที่เร่ง turbo (Aggressive Turbo Boost, EPP) จะไม่ถูกแนะนำบนเครื่องนั้นอีก กด "Reset Heat Guard" ในหน้า Auto Game Mode เพื่อลืมขั้นที่จำไว้ เกณฑ์อุณหภูมิแก้ได้ที่ `HeatCpu` / `HeatGpu` ใน `settings.json`
- เปิดได้ครั้งละหนึ่งหน้าต่าง (แบบ Administrator) เพราะสองตัวจะแย่งกันตรวจจับเกมและแย่งปุ่มลัด
- อุณหภูมิอ่านจากสิ่งที่ Windows และไดรเวอร์ NVIDIA เปิดให้ (ACPI thermal zone, `nvidia-smi`) จึงไม่ต้องติดตั้ง kernel driver เพิ่ม ค่า CPU เป็นค่าประมาณจาก thermal zone ที่ร้อนที่สุด

## ปิดหน้าต่าง หรือให้ทำงานอยู่เบื้องหลัง

กดกากบาทแล้วโปรแกรมจะถามว่าให้ **ทำงานอยู่เบื้องหลัง** หรือ **ปิดโปรแกรม** ติ๊ก "จำตัวเลือกนี้ไว้" เพื่อไม่ต้องถามอีก (เปลี่ยนได้ที่ Settings & Backups > When I press X)

- ตอนอยู่เบื้องหลัง หน้าต่างจะหายไปแต่ Auto Game Mode และ Heat Guard ยังทำงาน ไอคอน Atomic จะอยู่ข้างนาฬิกา (อาจอยู่ในลูกศร ^ ของไอคอนที่ซ่อนไว้ ลากออกมาวางบน taskbar ได้) คลิกเพื่อเปิดหน้าต่างกลับมา คลิกขวาเพื่อเปิดหรือปิดโปรแกรม
- ดับเบิลคลิก `Atomic.exe` อีกครั้งขณะที่โปรแกรมซ่อนอยู่ จะเปิดหน้าต่างเดิมกลับมา ไม่เปิดตัวใหม่ซ้อน

## ความปลอดภัย

- ก่อนแก้ค่าใด ค่าเดิมจะถูกบันทึกไว้ที่ `C:\ProgramData\OptiForge\backup.json` การปิดสวิตช์ของ tweak จะคืนค่าเดิมนั้นกลับ
- สร้าง System Restore point ก่อนการเปลี่ยนแปลงครั้งแรกของแต่ละครั้งที่เปิดโปรแกรม เฉพาะเมื่อ System Protection ของ Windows เปิดอยู่แล้ว โปรแกรมจะไม่เปิด System Protection เอง (ปิดการสร้าง restore point ได้ใน Settings)
- สิ่งเดียวที่ย้อนในโปรแกรมไม่ได้คือ Store app ที่ถูกถอน ต้องติดตั้งใหม่จาก Microsoft Store
- **One-Click Boost ไม่แตะหมวด Advanced** (ปิด Memory Integrity / Spectre mitigations) เพราะแลกกับความปลอดภัย ต้องเปิดเองทีละตัว
- บน Laptop การตั้งค่าพลังงานจะมีผลเฉพาะตอนเสียบปลั๊ก ไม่กระทบอายุแบตเตอรี่
- ทุกการกระทำถูกบันทึกที่ `C:\ProgramData\OptiForge\optiforge.log`

## Build

```
build.bat
```

ต้องมี .NET 8 SDK ได้ไฟล์เดียวคือ `Atomic.exe` ในโฟลเดอร์ของโปรเจกต์ (ไฟล์นี้ต้องมี .NET 8 Desktop Runtime ในเครื่อง ส่วนไฟล์ในหน้า Releases รวม runtime มาแล้ว) เปิดแบบอ่านอย่างเดียว (ไม่ขอสิทธิ์ admin, แก้ค่าไม่ได้) ด้วย `Atomic.exe --no-elevate`

## โครงสร้างโค้ด

- `Core/Catalog.cs` รายการ tweak ทั้งหมด เพิ่ม/แก้ tweak ที่นี่
- `Core/Tweak.cs` engine สำหรับ apply / revert / ตรวจสถานะ และ backup
- `Core/SystemInfo.cs` สแกนฮาร์ดแวร์และ Health check
- `Core/Cleaner.cs` ตัวล้างไฟล์ขยะและ Startup manager
- `Core/LiveStats.cs` เก็บสถิติสด
- `Core/GameMode.cs` Auto Game Mode (ตรวจจับเกม, ปิด/เปิดแอปตามรายการ), `Core/Thermal.cs` อุณหภูมิ, `Core/HeatGuard.cs` ตัวลด turbo เมื่อเครื่องร้อน
- `Core/Lang.cs` ระบบแปล, `Core/Lang.th.cs` ข้อความไทยของ UI, `Core/CatalogTh.cs` ชื่อและคำอธิบาย tweak ภาษาไทย
- `Core/Palette.cs` ชุดสีดำแดงที่ใช้ทั้งโปรแกรม (ไฟล์โลโก้ `Logo.png` กับ `Atomic.ico` ไม่ได้อยู่ใน repo ถ้าไม่มี โปรแกรมจะใช้ไอคอนปกติของ Windows และแสดงแค่ชื่อ ATOMIC)
- `Controls/Backdrop.cs` ภาพพื้นหลังนิ่งแบบแสงหลอมเหลว (คำนวณครั้งเดียวตอนเปิด), `Controls/Fx.cs` ตัวช่วย animation
- `Fonts/` ฟอนต์ Kanit (สัญญาอนุญาต SIL Open Font License อยู่ใน `Fonts/OFL.txt`)
- `Pages/` หน้าจอแต่ละหน้า, `Themes/Theme.xaml` สไตล์และ animation ของปุ่ม สวิตช์ เมนู

ข้อความใหม่ใน UI ให้เขียนเป็นอังกฤษผ่าน `L.T("...")` (หรือ `{l:T '...'}` ใน XAML) แล้วเพิ่มคำแปลใน `Lang.th.cs` ถ้าไม่มีคำแปลจะแสดงเป็นอังกฤษ
